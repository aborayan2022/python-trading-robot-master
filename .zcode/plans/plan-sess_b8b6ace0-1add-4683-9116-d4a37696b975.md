## معيار القبول قبل الـpush
1. كل الاختبارات تمر (pytest كامل) + ruff نظيف + CI أخضر.
2. كل الباكتيستات مُعاد تشغيلها بنسخة مصلحة، والتقارير والجدول في التقرير الاستشاري متطابقة مع JSON الجديد.

4. push واحدة إلى origin برسالة توضح الإصلاحات.
